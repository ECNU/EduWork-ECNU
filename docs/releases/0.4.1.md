EduWork@ECNU 0.4.1

[中文](#cn-ecnu-041) | [English](#en-ecnu-041)

<h2 id="cn-ecnu-041">中文</h2>

基于 **EduWork 0.4.1 / DSH 0.2.0-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。

- 接入学校提供的联网搜索与校园网搜索，沿用统一认证授权。
- 网页搜索使用官方工具入口，网页读取与浏览器自动化沿用 DSH 官方实现。
- 学校图像服务支持生成与编辑，编辑保留原图并另存结果；同步公版的图像编辑及 macOS 拖拽安装改进。
- 保留统一认证、学校模型与额度、校内视觉辅助及活跃心跳；继续保留用户配置与数据。

感谢 [szhgoldeneye](https://github.com/szhgoldeneye) 的学校搜索与媒体接入贡献（[#40](https://github.com/ECNU/EduWork-ECNU/pull/40)），感谢 [JJasonSun](https://github.com/JJasonSun)、[freedomkk-qfeng](https://github.com/freedomkk-qfeng) 及 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 上游团队。

<h2 id="en-ecnu-041">English</h2>

Based on **EduWork 0.4.1 / DSH 0.2.0-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**.

- Add institution-provided web and campus search through unified sign-in authorization.
- Use the official search tool entry point and DSH's official page-reading and browser automation implementations.
- The institution image service supports generation and editing, preserving originals and saving edited results separately. Includes the public edition's image editing and macOS drag-and-drop installation improvements.
- Retain unified sign-in, institution models and quotas, vision assistance, activity heartbeats, and existing user configuration and data.

Thanks to [szhgoldeneye](https://github.com/szhgoldeneye) for the institution search and media integration ([#40](https://github.com/ECNU/EduWork-ECNU/pull/40)), [JJasonSun](https://github.com/JJasonSun), [freedomkk-qfeng](https://github.com/freedomkk-qfeng), and the upstream [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) team.
