EduWork@ECNU 0.4.9

[中文](#cn-049) | [English](#en-049)

<h2 id="cn-049">中文</h2>

基于公版 **EduWork 0.4.9**，内核升级至 **DSH 0.2.1-rc.3**，保留学校登录、授权模型、校园智搜和学校图像能力。提供 **Windows x64**、**macOS Apple Silicon（arm64）** 与新增的 **macOS Intel（x64）** 桌面包。

- **邮件安全修复**：更新邮件助手内嵌的 Nodemailer / Mailparser，修复读取特制邮件地址时可能长时间无响应的拒绝服务问题，并更新相关间接依赖。邮件插件升级为 **@eduwork/dsh-mail 0.2.3**（[#223](https://github.com/ECNU/EduWork/pull/223)）。问题由中国科大词元工坊反馈。

- **选段批注**：选中回复中的文字后添加批注，多条批注可以一起发送；支持来源编号、编辑管理和已发送批注展示，沿用原生输入框、引用和草稿机制。以独立 npm 插件预装（公版 [#154](https://github.com/ECNU/EduWork/pull/154)、[#200](https://github.com/ECNU/EduWork/pull/200)）。
- **Windows 安装与升级**：改进安装引导、快捷方式和完成后的启动选项；确认覆盖安装时保留用户数据，并在失败时回滚。修复差分升级后第一次启动可能白屏、重新打开才能恢复的问题（公版 [#147](https://github.com/ECNU/EduWork/pull/147)、[#211](https://github.com/ECNU/EduWork/pull/211)）。
- **启动与内核**：升级 DSH 0.2.1-rc.3，接入官方菜单、窗口和技能事件及草稿恢复；保留用户的预设和插件启停选择。启动加载页增加品牌 Logo（公版 [#213](https://github.com/ECNU/EduWork/pull/213)、[#214](https://github.com/ECNU/EduWork/pull/214)、[#215](https://github.com/ECNU/EduWork/pull/215)）。
- **插件体验**：审批提示随中英文界面切换；延后加载邮件协议库、PDF 引擎与搜索浏览器库，减少启动阶段的加载工作。更新邮件、文献、OIDC 和 Studio 的 npm 装配版本（公版 [#201](https://github.com/ECNU/EduWork/pull/201)、[#202](https://github.com/ECNU/EduWork/pull/202)、[#203](https://github.com/ECNU/EduWork/pull/203)、[#208](https://github.com/ECNU/EduWork/pull/208)、[#217](https://github.com/ECNU/EduWork/pull/217)）。

<h2 id="en-049">English</h2>

Based on public **EduWork 0.4.9**, with **DSH 0.2.1-rc.3**, while retaining school sign-in, authorized models, campus search and school image services. Desktop packages are available for **Windows x64**, **macOS Apple Silicon (arm64)** and the new **macOS Intel (x64)** target.

- **Mail security fix:** Update the Nodemailer / Mailparser code embedded in the mail assistant to fix denial of service caused by crafted email addresses, along with related transitive dependencies. Upgrade the plugin to **@eduwork/dsh-mail 0.2.3** ([#223](https://github.com/ECNU/EduWork/pull/223)). Reported by 中国科大词元工坊 (USTC).

- **Response annotations:** Select text in an assistant reply, add comments and send several annotations together. Source numbers, editing controls and sent annotation cards build on the native composer, quotes and drafts. Included as a standalone npm plugin (public [#154](https://github.com/ECNU/EduWork/pull/154), [#200](https://github.com/ECNU/EduWork/pull/200)).
- **Windows installation and updates:** Improve installation guidance, shortcuts and launch options. Confirmed replacement preserves user data and rolls back on failure. Fix a possible blank screen on the first launch after a delta update that previously required reopening the application (public [#147](https://github.com/ECNU/EduWork/pull/147), [#211](https://github.com/ECNU/EduWork/pull/211)).
- **Startup and runtime:** Upgrade to DSH 0.2.1-rc.3, integrate upstream menu, window and skill events, and adopt draft restoration while preserving preset and plugin choices. Add the product logo to the loading screen (public [#213](https://github.com/ECNU/EduWork/pull/213), [#214](https://github.com/ECNU/EduWork/pull/214), [#215](https://github.com/ECNU/EduWork/pull/215)).
- **Plugin experience:** Localize approval prompts with the interface language. Defer mail protocol libraries, the PDF engine and search browser libraries to reduce startup loading. Update the pinned mail, literature, OIDC and Studio npm packages (public [#201](https://github.com/ECNU/EduWork/pull/201), [#202](https://github.com/ECNU/EduWork/pull/202), [#203](https://github.com/ECNU/EduWork/pull/203), [#208](https://github.com/ECNU/EduWork/pull/208), [#217](https://github.com/ECNU/EduWork/pull/217)).
