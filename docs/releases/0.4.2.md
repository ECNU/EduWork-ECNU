EduWork@ECNU 0.4.2

[中文](#cn-ecnu-042) | [English](#en-ecnu-042)

<h2 id="cn-ecnu-042">中文</h2>

基于 **EduWork 0.4.2 / DSH 0.2.0-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。

- 修复会话搜索与活跃会话自动保存之间的冲突，避免搜索干扰正在进行的对话（[#103](https://github.com/ECNU/EduWork/pull/103)）。
- 修复联网搜索读取配置时报错的问题；搜索配置修改及时生效，并正确遵守服务的启用、禁用状态（[#87](https://github.com/ECNU/EduWork/pull/87)）。
- 机构账号、邮件助手与 Studio 界面跟随应用语言设置，保留机构自定义文案（[#92](https://github.com/ECNU/EduWork/pull/92)）。
- 修复 Studio 视频创作选择“关闭背景音乐”后仍可能添加音乐的问题（[#73](https://github.com/ECNU/EduWork/pull/73)）。
- 内置技能卡片显示实际发布方；任务通知适配当前内核的会话接口（[#94](https://github.com/ECNU/EduWork/pull/94)、[#96](https://github.com/ECNU/EduWork/pull/96)）。
- 改善 macOS 配置文件打开和安装后 DMG 清理，修复部分外部编辑器无法正常启动的问题（[#89](https://github.com/ECNU/EduWork/pull/89)、[#97](https://github.com/ECNU/EduWork/pull/97)、[#99](https://github.com/ECNU/EduWork/pull/99)）。
- 改善机构插件兼容性与登录时的系统时间偏差提示，完善服务请求和媒体凭据的隔离（[#88](https://github.com/ECNU/EduWork/pull/88)、[#98](https://github.com/ECNU/EduWork/pull/98)、[#100](https://github.com/ECNU/EduWork/pull/100)）。
- 修正学校联网搜索、校园搜索与浏览器技能卡片的名称和说明，准确区分学校搜索与官方浏览器的用途（[#43](https://github.com/ECNU/EduWork-ECNU/pull/43)）。
- 更新学校图像创作技能：默认约 1K 出图，由助手自行扩写提示词；文生图未指定人物背景时默认中国人形象，编辑保留参考人物身份。明确指定的尺寸、人物和编辑要求优先，并适配学校新图像模型的常用画幅（[#45](https://github.com/ECNU/EduWork-ECNU/pull/45)）。

感谢 [wf0229](https://github.com/wf0229)、[JunieXD](https://github.com/JunieXD)、[JJasonSun](https://github.com/JJasonSun)、[freedomkk-qfeng](https://github.com/freedomkk-qfeng) 的贡献，以及 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 上游团队。

<h2 id="en-ecnu-042">English</h2>

Based on **EduWork 0.4.2 / DSH 0.2.0-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**.

- Fix conflicts between conversation search and automatic saving of active sessions, preventing searches from disrupting ongoing conversations ([#103](https://github.com/ECNU/EduWork/pull/103)).
- Fix configuration errors in web search. Updated search settings take effect on subsequent requests, and enabled/disabled provider settings are respected ([#87](https://github.com/ECNU/EduWork/pull/87)).
- Organization accounts, Mail Assistant, and Studio now follow the application language while preserving institution-specific wording ([#92](https://github.com/ECNU/EduWork/pull/92)).
- Fix Studio video creation adding background music when the user has turned it off ([#73](https://github.com/ECNU/EduWork/pull/73)).
- Bundled skill cards show their actual publisher; task notifications use the current kernel's session interface ([#94](https://github.com/ECNU/EduWork/pull/94), [#96](https://github.com/ECNU/EduWork/pull/96)).
- Improve opening configuration files and cleaning up installation DMGs on macOS, and fix startup failures in some external editors ([#89](https://github.com/ECNU/EduWork/pull/89), [#97](https://github.com/ECNU/EduWork/pull/97), [#99](https://github.com/ECNU/EduWork/pull/99)).
- Improve institutional plugin compatibility and clock-skew guidance during sign-in, and strengthen isolation of service requests and media credentials ([#88](https://github.com/ECNU/EduWork/pull/88), [#98](https://github.com/ECNU/EduWork/pull/98), [#100](https://github.com/ECNU/EduWork/pull/100)).
- Correct the names and descriptions of university web search, campus search, and browser skill cards, clarifying the roles of university search and the official browser ([#43](https://github.com/ECNU/EduWork-ECNU/pull/43)).
- Update university image creation guidance: default to roughly 1K output and prompt expansion by the assistant. Text-to-image requests default to Chinese people when no background is specified; editing preserves reference subjects' identities. Explicit size, subject, and editing requirements take precedence. Add common canvas sizes for the university's new image model ([#45](https://github.com/ECNU/EduWork-ECNU/pull/45)).

Thanks to [wf0229](https://github.com/wf0229), [JunieXD](https://github.com/JunieXD), [JJasonSun](https://github.com/JJasonSun), [freedomkk-qfeng](https://github.com/freedomkk-qfeng), and the upstream [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) team.
