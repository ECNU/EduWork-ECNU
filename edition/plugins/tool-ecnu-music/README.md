# Music Studio · 音乐工作室

**简体中文** | [English](README_EN.md)

为 EduWork 华师版提供独立的音乐侧栏：歌曲创作、旋律规划、翻唱改编、音频转谱、候选试听与 ABC 五线谱预览。音乐工作室与 Knowledge Studio 分开，新打开时默认展开为宽工作区；可点击「收回侧栏」与对话并排使用。宽屏采用三栏布局，窄侧栏中分页操作，切换时保留当前草稿。

登录学校账号后，在带工作区的对话侧栏打开「音乐工作室」，填写歌词和风格即可提交。生成完成后选择产物试听或看谱；可编辑 ABC，再用这份谱创作新版本。翻唱与转谱使用工作区内的参考音频路径。Seed 留空随机，填写则覆盖；生成可选择 1 或 2 首候选。

界面与 `ecnu-music` 技能复用同一组 Host 工具、权限检查和 image/TTS 的学校登录接口，不接触 Token。标题、歌词、参数、版本来源与下载产物保存在当前工作区。ABC 排版不保证音符准确，也不等于完整管弦乐总谱；本版不提供分轨编辑或精确时长控制。

由华师版发行配置装配，公版暂不包含。详细配置、工具说明、本地交互预览与验证方法见[音乐接入指南](../../../docs/MUSIC.md)。仅导入 SKILL.md 不会安装原生工具或界面。
