# 🦁 小花狮桌面宠物 · ECNU 版专属插件

面向华东师范大学师生的一只桌面陪伴宠物——「幸福花狮」。它基于官方「幸福花狮」表情包形象制作，是一只住在桌面上的原创 Electron 桌面宠物：会随时间饥饿、陪你学习、打工、玩小游戏、生病了要去校医院，清晨问候、深夜陪你肝论文。

> 本插件为 ECNU 版专属插件：当前形象仅有花狮一款，作为华东师范大学发行版的专属扩展提交。

## 功能

- 状态系统：饱食 / 能量 / 心情随时间变化，离线也会饿
- 喂食：樱桃、小笼包、红烧狮子头等 8 种食物，按等级解锁
- 学习升级：自习室刷题 / 蹭大师讲座 / 期末冲刺，攒知识值升级（狮崽 → 大师狮 🎓）
- 小游戏：樱桃雨、抢座大作战、师大知识问答
- 打工：助教 / 占座大使 / 实验室助手等 5 个岗位，赚花狮币
- 随机事件：樱花、银杏、图书馆抢座、上课睡觉被抓……
- 时间感知：清晨问候、整点报时、深夜陪肝论文、到点睡觉
- 生病与治疗：校医院门诊、多喝热水、睡觉自愈
- 聊天：可配置 OpenAI 兼容接口（DeepSeek / SiliconFlow 等），Key 仅保存在本机
- 动作与彩蛋：摸头、连点生气、吃饭吧唧嘴、打工工作台、拖拽、双击……

## 使用

独立运行：

```bash
cd electron
npm install        # 首次
npm start
```

或直接双击 `启动小花狮.bat`（首次自动安装依赖）。打包 Windows x64 安装包：`npm run build`。

**接入 ECNU 发行版的方式（待与维护者确认）**：本插件当前作为独立组件提交；是否注册进 `edition/distribution.json`、是否随 ECNU 发行包分发、以及后续是否挂接 EduWork 桌面扩展点，请在本 PR 评审中与维护者对齐后再落地。
