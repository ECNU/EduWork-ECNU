# School music tools

[简体中文](README.md) | **English**

Provides music generation, planning, audio rearrangement, music transcription, asynchronous job queries and downloads for EduWork's ECNU edition. Reuses the Host school-account authorization interface used by image/TTS; skills and models never receive tokens.

Assembled through the edition distribution and used with the `ecnu-music` skill. See the [music integration guide](../../../docs/MUSIC.md) for configuration, tools and validation. Importing SKILL.md alone does not install the native tools.
