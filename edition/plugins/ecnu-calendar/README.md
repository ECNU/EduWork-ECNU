# ECNU 校历

**简体中文** | [English](README_EN.md)

启用后自动把内置学年校历写入学校专属来源。打开日历即可查看，无须先聊天；不读取学校账号或请求学校接口。

2026–2027 数据依据[本科生院公开校历](https://bksy.ecnu.edu.cn/b6/33/c40558a767539/page.htm)整理，包含教学/考试周、老生注册、寒假及暑期短学期。具体课程、调休和后续通知不在本数据集内。全天结束日期含当天。

公版的“日历与日程管理”技能附加本学年参考资料，可查询安排、记私人备注和规划复习。公共校历不按账号复制；个人课表将来使用独立账号来源。学校数据不会替换用户自建日程或私人设置。

数据版本和来源在 `data/2026-2027.json`，事件编号在修订时保持不变。新版必须递增 revision，日期改变须携带原实例信息；旧包初始化被拒绝时保留新版缓存，不自动降级。当前用于本地结合试点，部署前仍需校历业务核对与目标产品验收。

未来取数、更新频率、登录和重连重试由机构数据插件实现，通过公版来源操作对象提交。当前无定时网络请求和真实个人课表接入。到点提醒由公版生成记录，桌面系统通知由产品通知通道提供，不由机构数据插件另做一套。
