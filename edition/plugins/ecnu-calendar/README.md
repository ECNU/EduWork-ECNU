# ECNU 校历

**简体中文** | [English](README_EN.md)

ECNU 机构侧的校历数据层：只持有学校官方校历的结构化数据和由它直接推出的日期问答，不把教学周、考试周写成日历事件。启用后提供 `ctx.ecnuCalendar` 服务（`describeDate(date)` 返回学期、教学周、单双周、阶段或假期）；周视图标题、月视图周次和阶段色带等展示，待公版日历的展示插槽（EduWork #186）落地后接入。不读取学校账号，也不发起网络请求。

2026–2027 数据依据[本科生院公开校历](https://bksy.ecnu.edu.cn/b6/33/c40558a767539/page.htm)整理：秋季学期 2026-09-14 开课（18 周，教学至 2027-01-01，期末考试 2027-01-04 至 01-15）、寒假 2027-01-18 至 02-20、春季学期 2027-02-22 开课（18 周，教学至 2027-06-13，期末考试 2027-06-14 至 06-25）、暑期短学期 2027-06-28 至 07-23。注册等具体事项以普通事件记录。官方未标明周次的暑期短学期不给出周号，也不推断。

数据结构与校验规则见 `data/2026-2027.json`：学期按 `firstDay` 每 7 天一周，末周以 `lastDay` 截断；周次不因节假日改变；阶段、假期、学期三类区间互不重叠；加载时全部校验，坏数据立即报错。字段名暂按机构侧整理，待公版校历格式定稿后对齐。个人课表接入（教学班＋完整上课实例）由后续机构数据插件实现，走公版订阅管道的来源机制。
