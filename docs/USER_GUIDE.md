# EduWork@ECNU 使用指南

[返回项目首页](../README.md)

EduWork@ECNU 在本机运行，学校登录用于连接配置的企业模型和服务。它仍支持个人 API Key、其他模型、本机工作区和公版的全部公共功能。

## 安装与首次登录

1. 将完整 ECNU 桌面包解压到可写目录。学校分发的客户端已配好服务，直接运行即可。GitHub CI 包仅供维护者装配，不能作为学校开箱即用包；不要拆开程序和资源目录。
2. 在登录引导或“设置 → 学校/企业服务”选择华东师范大学，按照浏览器提示登录。需要创建模型凭据时，在引导中确认授权。
3. 返回客户端，确认企业模型已连接，再选择工作区开始任务。也可以跳过学校模型，在模型设置中添加个人服务。

尚未公开发行时，不把源码 ZIP 或 CI Web 验证产物当作完整桌面包。macOS 尚在适配计划中。

## 账户、配额和注销

点击左下角头像打开账户菜单，查看已登录姓名、使用情况、重置时间和资源池。可展开明细、刷新配额或退出登录。具体数值与可用资源以服务端返回为准；个人模型服务的额度不在这里展示。

配额扩展只查询配置的 ECNU 账户档案，保留配额窗口和资源池信息。公版 OIDC 只负责身份、Key 和模型；配额是本发行的学校扩展。

## 学校配置与个人设置

学校统一维护企业登录、模型目录与能力、上下文和输出上限、媒体服务、品牌、服务开关及更新源。完整学校配置随客户端版本更新，使用者无需编辑文件，也无需为了模型能力变化重新登录。设置中仍可添加个人模型，并保留已保存的个人偏好。

当前 `ecnu-max` 支持原生图片输入，上下文为 512K（524,288 tokens），最大输出为 384K（393,216 tokens）。原生图片直接送给所选模型；图片辅助仅作用于配置范围内的纯文本模型。标准模式由 DSH 在上下文压力达到阈值时自动压缩。

每个版本读取对应的 `config/eduwork.<产品版本>.jsonc`，升级补入新配置，旧配置保留用于失败回退。旧 `config/eduwork.jsonc` 不再作为新版学校发行的生效配置。会话、工作区、记忆、个人 Provider 和 Key、默认模型选择及已保存的用户偏好不会被学校配置替换。

仓库和 CI 仅提供模板。实际 Client ID 等部署参数由维护者在本机加入学校发行包，详见[配置示例](../edition/desktop-examples/README.md)。这些参数及账号令牌不提交公开仓库。

## 学校能力与公共能力

- 校内搜索由学校插件提供。通用网页和文献搜索、技能中心、Studio、文件预览、记忆、邮件、本机语音来自公版。
- 学校图像与语音服务由公版的 OpenAI 兼容适配器按配置和账号权限启用，不再包含学校媒体插件。企业示例含 `media` 段；`media.providers: []` 可显式关闭云端媒体，旧配置缺省时沿用本版学校默认值。缺少远程语音服务时，可使用已就绪的本机 TTS/ASR。
- 活跃心跳默认关闭，只有在兼容服务部署完成且发行配置显式开启后才工作；不能因为某学校支持，就向其他机构自动发送请求。
- 对话与 Studio 共用生成、预览和下载。Studio 默认折叠，主动打开或关闭后会记住偏好。

## 常见问题

**没有显示学校入口**：确认使用学校提供的已配置 ECNU 发行包；若仍缺失入口，请导出诊断并联系维护者，无需自行修改配置。

**浏览器已登录，客户端仍未连接模型**：检查引导是否还有模型凭据授权待确认，并在学校/企业服务页面查看实际连接状态。保留错误信息反馈维护者，不要复制或公开账号令牌。

**学校服务暂不可用**：可配置自己的模型继续一般工作。校内搜索、学校配额和远程媒体需要各自的学校服务支持，不能用个人模型连接状态判断它们已就绪。

**程序移动后找不到工作区文件**：移动整个绿色目录前应完全退出。外部工作区文件仍留在原位置，不会随程序目录一起移动。用户会话与配置不能作为缓存清理。

公共使用方式见 [EduWork 使用指南](https://github.com/ecnu/EduWork/blob/main/docs/USER_GUIDE.md)，学校发行的源码装配见[构建与协作](BUILD.md)。
