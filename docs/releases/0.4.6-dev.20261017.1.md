<h2 id="cn-046-dev">中文</h2>

基于 **EduWork 0.4.6 / DSH 0.2.1-rc.2**，提供 **Windows x64** 与 **macOS arm64** 开发测试包，继续提供学校统一认证、学校模型、校园与联网搜索及学校图像能力。

- 网页操作统一复用公版接入的 DSH 官方浏览器与 Playwright MCP，保留原有浏览器启停选择，网页交互遵循工作区授权；校园与联网搜索继续使用学校服务。
- 恢复官方可选语音输入，可在插件页启用并按需准备识别模型；支持启用官方开发者工具，查看会话数据并辅助排查问题。
- Office 技能适配新版官方处理流程，按任务加载文档、表格和演示文稿的操作指导；继续复用官方 LibreOffice Kit 完成转换、导出和公式重算。
- 文献插件更新至 `@eduwork/dsh-literature@0.1.3`，修复新版内核下 PDF 链接解析的兼容问题。
- 改善旧会话导入和自动化任务迁移，保留已有任务与自定义预设；修正切换工作目录后的邮件附件、图片编辑和音频文件读取，并完善学校模型接口兼容。

语音输入默认关闭。浏览器插件关闭再开启后，请重启应用再继续已有会话，无需删除历史。

本版为开发预发布，不替代稳定版 0.4.3。软件更新保持开启并保留用户设置，可在设置中选择更新渠道或关闭更新；仅选择稳定渠道的用户不会收到本版。

<h2 id="en-046-dev">English</h2>

Based on **EduWork 0.4.6 / DSH 0.2.1-rc.2**, with development test packages for **Windows x64** and **macOS arm64**, retaining university sign-in, models, campus and web search, and university image services.

- Reuse the public core's official DSH browser and Playwright MCP integration, preserving the browser's enabled/disabled state and applying workspace permissions to interactions. Campus and web search continue to use university services.
- Restore optional upstream voice input, which can be enabled in Plugins with its recognition model prepared on demand. Optional upstream Developer Tools provide session inspection and troubleshooting.
- Adapt Office skills to the updated official workflow, loading task-specific guidance for documents, spreadsheets, and presentations. Continue using the official LibreOffice Kit for conversion, export, and formula recalculation.
- Update the literature plugin to `@eduwork/dsh-literature@0.1.3`, fixing PDF-link extraction compatibility with the new runtime.
- Improve historical conversation imports and scheduled-task migration while preserving existing tasks and custom presets. Fix mail attachment, image-editing, and audio input paths after working-directory changes, and improve university model adapter compatibility.

Voice input is disabled by default. After disabling and re-enabling the browser plugin, restart the app to continue an existing conversation; its history does not need to be deleted.

This development prerelease does not replace stable 0.4.3. Software updates remain enabled while preserving user preferences. Choose an update channel or disable updates in Settings; stable-only users will not receive this release.
