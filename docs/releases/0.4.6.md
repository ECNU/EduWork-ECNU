EduWork@ECNU 0.4.6

[中文](#cn-046) | [English](#en-046)

<h2 id="cn-046">中文</h2>

基于 **EduWork 0.4.6 / DSH 0.2.1-rc.2**，提供 **Windows x64** 与 **macOS arm64** 桌面包。本次合并自稳定版 0.4.3 以来的更新，继续提供学校统一认证、学校模型、校园与联网搜索及学校图像能力。

- 新增可选桌面宠物，内置红/蓝“小页”、“大肥鱼”和“小花狮”，支持切换形象、拖拽、收边和空闲打盹，与任务和通知状态联动。桌宠通过独立 npm 插件装配，默认关闭，可在“设置 → 桌面宠物”中开启。
- Office 技能、Studio 文档处理与预览复用官方能力，支持旧 DOC、XLS、PPT 的读取与转换、PDF 导出和表格公式重算。改善自适应预览的反复缩放与闪动；旧 DOC 编辑前转换为 DOCX，保留原文件。
- 网页操作统一复用 DSH 官方浏览器与 Playwright MCP，保留原有浏览器启停选择，交互遵循工作区授权；华东师大校园智搜继续通过学校服务提供校园与联网搜索，并引导回答附上引用。
- 恢复官方可选语音输入，可在插件页启用并按需准备识别模型；支持启用官方开发者工具，查看会话数据并辅助排查问题。文献插件更新至 `@eduwork/dsh-literature@0.1.3`，修复新版内核下 PDF 链接解析的兼容问题。
- 在设置中增加软件更新开关，保留用户选择；更新渠道可单独切换，关闭软件更新不影响学校签名配置更新。开发版也可继续升级到正式版。
- 增加 Windows 文件级增量更新与 macOS Sparkle 增量更新，保留完整包回退；精简随包运行时与未使用的资源，减少下载和安装空间。**Windows 从 0.4.3 升级到本版仍使用完整包；支持增量的客户端在有匹配差分时才下载增量。**
- macOS 更新统一到应用内面板并支持后台下载；任务运行时退出或立即安装更新会先确认。改善 Windows 启动与工作区沙箱权限处理，在实际遇到可修复的权限问题时给出提示。
- 修正后台子代理和目标模式的完成提醒时机，补齐目标受阻提醒，加快清理后的退出；视频模板渲染缓存移出安装目录，改善只读安装目录下的使用。
- 改善旧会话导入和自动化任务迁移，保留已有任务与自定义预设；修正切换工作目录后的邮件附件、图片编辑和音频文件读取，并完善学校模型接口兼容。
- 提前接入公版 [#178](https://github.com/ECNU/EduWork/pull/178) 与 [#179](https://github.com/ECNU/EduWork/pull/179)：移除 Windows 启动与错误窗口多余的菜单，主窗口菜单随界面语言切换；个人概览、桌面宠物、个性化、邮件助手和关于使用各自的图标。

语音输入默认关闭。浏览器插件关闭再开启后，请重启应用再继续已有会话，无需删除历史。

<h2 id="en-046">English</h2>

Based on **EduWork 0.4.6 / DSH 0.2.1-rc.2**, with desktop packages for **Windows x64** and **macOS arm64**. This release combines updates since stable 0.4.3 and retains university sign-in, models, campus and web search, and university image services.

- Add an optional desktop pet with red and blue Page, Dafeiyu, and Huashi appearances, supporting dragging, edge docking, idle sleep, and task and notification status. Distributed as an independent npm plugin; disabled by default and available in Settings → Desktop Pet.
- Reuse official Office processing and preview capabilities in skills and Studio, including legacy DOC, XLS, and PPT conversion, PDF export, and spreadsheet formula recalculation. Improve repeated resizing and flicker in adaptive previews. Convert legacy DOC files to DOCX before editing while preserving the originals.
- Reuse the official DSH browser and Playwright MCP, preserving the browser's enabled/disabled state and applying workspace permissions to interactions. ECNU Campus Smart Search continues to provide campus and web search through university services and guides responses to include citations.
- Restore optional upstream voice input, enabled in Plugins with its recognition model prepared on demand, and optional Developer Tools for session inspection and troubleshooting. Update the literature plugin to `@eduwork/dsh-literature@0.1.3`, fixing PDF-link extraction compatibility.
- Add a software update switch in Settings and preserve user preferences. The update channel remains a separate choice; disabling software updates does not disable signed university configuration updates. Development releases can upgrade to stable releases.
- Add file-level delta updates on Windows and Sparkle delta updates on macOS, with full-package fallback. Trim bundled runtimes and unused resources to reduce download and installed sizes. **Windows upgrades from 0.4.3 still use the full package; delta-capable clients use incremental downloads only when a matching delta is available.**
- Bring macOS updates into the in-app panel with background downloading, and ask before quitting or installing while tasks are running. Improve Windows startup and workspace sandbox permissions, offering targeted guidance after an actual, repairable permission failure.
- Correct completion notifications for background subagents and goal mode, report blocked goals, and exit promptly after cleanup. Keep video-template rendering caches outside the installation directory to improve operation in read-only installations.
- Improve historical conversation imports and scheduled-task migration while preserving existing tasks and custom presets. Fix mail attachment, image-editing, and audio input paths after working-directory changes, and improve university model adapter compatibility.
- Include the public core's [#178](https://github.com/ECNU/EduWork/pull/178) and [#179](https://github.com/ECNU/EduWork/pull/179) early: remove irrelevant menus from Windows startup and error windows, localize the main window's menus, and give Overview, Desktop Pet, Personalization, Mail Assistant, and About distinct icons.

Voice input is disabled by default. After disabling and re-enabling the browser plugin, restart the app to continue existing conversations; history does not need to be deleted.
