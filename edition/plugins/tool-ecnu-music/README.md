# 音乐创作插件

**简体中文** | [English](README_EN.md)

为 EduWork 华师版提供对话音乐工具：歌曲创作、旋律规划、翻唱改编、音频转谱、作品续查与 ABC 五线谱排版。配合 `ecnu-music` 技能即可在对话中使用，也可通过独立的 Music Studio 侧栏操作。

登录学校账号后，在带工作区的对话里描述歌词和风格即可创作；生成完成后下载实际产物，可编辑 ABC 并创作新版本。翻唱与转谱使用工作区内的参考音频路径。Seed 留空随机，填写则覆盖；生成可选择 1 或 2 首候选。

`ecnu_music_render_score` 将 ABC 文本或工作区 `.abc` 文件保存为独立离线 HTML，内含 SVG 五线谱排版、源 ABC、下载与打印 / 另存 PDF 功能。此步骤本地执行，无需登录，不调用音乐模型；无需打开 Music Studio。

完整作品可用 `ecnu_music_export_song` 导出为一个目录：`index.html` 同时展示歌词、音频播放器和五线谱，附带原音频、歌词文本和 ABC。支持循环、倍速、谱面放大与打印；音频通过相对路径引用，分享时复制整个目录即可离线使用。歌词与音符不做同步高亮。

当前内置 HTML 预览尚未接入同目录音频。完整作品页请通过预览顶部的浏览器按钮打开；对话同时提供独立音频入口，可用客户端音频预览播放。导出成功不代表内置播放已验证，此限制不需要修改学校账号或文件夹权限。

界面与 `ecnu-music` 技能复用同一组 Host 工具、权限检查和 image/TTS 的学校登录接口，不接触 Token。标题、歌词、参数、版本来源与下载产物保存在当前工作区。ABC 排版不保证音符准确，也不等于完整管弦乐总谱；本版不提供分轨编辑或精确时长控制。

由华师版发行配置装配，公版暂不包含。详细配置、工具说明、本地交互预览与验证方法见[音乐接入指南](../../../docs/MUSIC.md)。仅导入 SKILL.md 不会安装原生工具或界面。
