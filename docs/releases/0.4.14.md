# EduWork@ECNU 0.4.14

## 更新内容

- 基于 EduWork 0.4.14，内核升级至 DeepSeek Harness 0.2.2-rc.3，并更新配套插件。[公版运行时](https://github.com/ECNU/EduWork/pull/309)
- 新增日历与日程管理，默认按月打开，也可切换周视图。支持重复日程、私人备注与笔记、ICS 导入导出、日历订阅及提醒，也可在对话中操作日程。[日历](https://github.com/ECNU/EduWork/pull/248) · [界面改进](https://github.com/ECNU/EduWork/pull/326)
- 内置华东师范大学 2026–2027 学年全校校历，展示教学周、单双周、考试、寒暑假，以及本科生和研究生报到等校级事项。可通过学年总览跳转月份，校历与节假日数据支持通过签名配置更新。[学校公开校历](https://bksy.ecnu.edu.cn/b6/32/c40631a767538/page.htm) · [配置更新](https://github.com/ECNU/EduWork-ECNU/pull/103)
- 查看日程详情时保留当前浏览月份，切换日期或翻页时保留正在编辑的草稿。[浏览与编辑](https://github.com/ECNU/EduWork/pull/334)
- 新增首次使用引导，可从「应用 → 使用教程」再次打开学校在线教程，离线时也能阅读随包快速入门。引导结束时提示教程入口。[学校教程](https://github.com/ECNU/EduWork-ECNU/pull/95) · [入口与引导](https://github.com/ECNU/EduWork/pull/330)
- 邮件助手支持由用户开启定时新邮件检查，以只读方式获取发件人、主题和正文片段，保持邮件已读状态。桌宠可展示插件通知。[邮件提醒](https://github.com/ECNU/EduWork/pull/187) · [桌宠通知](https://github.com/ECNU/EduWork/pull/267)
- 应用在后台收到待处理通知时，Windows 任务栏和 macOS Dock 显示数量，Windows 任务栏图标支持闪烁提醒；修复运行时升级后部分会话通知无法送达的问题。[通知数量](https://github.com/ECNU/EduWork/pull/327) · [会话通知](https://github.com/ECNU/EduWork/pull/328)
- 改善启动等待与失败恢复。Windows 等待超过 30 秒时显示已等待时间和日志目录；无法解密本地凭据时保留原文件并继续启动，可重新登录恢复使用。[启动提示](https://github.com/ECNU/EduWork/pull/241) · [凭据恢复](https://github.com/ECNU/EduWork/pull/109)
- 开启软件更新后，运行期间会定期检查所选渠道，电脑唤醒或恢复网络后也会补查。[自动检查](https://github.com/ECNU/EduWork/pull/310)
- 远程访问 0.1.7 修复 iPadOS 16 页面白屏，改进思考翻译兼容性。[移动端修复](https://github.com/ECNU/EduWork/pull/312) · [思考翻译](https://github.com/ECNU/EduWork/pull/311)

## What's new

- Based on EduWork 0.4.14, with DeepSeek Harness 0.2.2-rc.3 and compatible plugin versions.
- A local calendar opens in month view and also supports week view, recurring events, private remarks and notes, ICS import/export, subscriptions and reminders. Conversation tools can manage events.
- Includes the official 2026–2027 ECNU academic calendar: teaching weeks, odd and even weeks, exams, breaks, and undergraduate and graduate arrivals. The academic-year overview links to individual months. Academic calendars and holiday data can be updated through signed configuration.
- Opening event details keeps the month you are browsing, and navigation preserves an unfinished event draft.
- A first-run tour points out **Application → User guide**, where users can reopen the school’s online guide or read the bundled quick start offline.
- Users can enable periodic read-only mail checks showing the sender, subject and a short excerpt, without changing read/unread status. The desktop pet can display plugin notifications.
- Pending notifications show a count on the Windows taskbar and macOS Dock while the app is in the background; the Windows taskbar can also flash. Session notification delivery after the Runtime upgrade is fixed.
- Startup feedback and recovery are improved. On Windows, waits longer than 30 seconds show elapsed time and the log location. If local credentials cannot be decrypted, the original file is preserved and startup continues so users can sign in again.
- When software updates are enabled, the app checks the selected channel periodically and after wake or network reconnection.
- Remote Access 0.1.7 fixes blank pages on iPadOS 16 and improves reasoning-translation compatibility.
