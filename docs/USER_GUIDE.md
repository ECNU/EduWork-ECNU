# EduWork@ECNU 使用指南

[返回项目首页](../README.md)

EduWork@ECNU 在本机运行，学校登录用于连接配置的企业模型和服务。它仍支持个人 API Key、其他模型、本机工作区和公版的全部公共功能。

## 安装与首次登录

1. Windows 将完整桌面包解压到可写目录；Mac 将 `.app` 放入应用程序目录。首次启动会下载并验证学校配置，无需重新装配 CI 原包。不要拆开程序和资源目录。
2. 在登录引导或“设置 → 学校/企业服务”选择华东师范大学，按照浏览器提示登录。授权后直接使用登录 Token 连接模型，无需再创建模型 Key。
3. 返回客户端，确认企业模型已连接，再选择工作区开始任务。也可以跳过学校模型，在模型设置中添加个人服务。

尚未公开发行时，不把源码 ZIP 或 CI Web 验证产物当作完整桌面包。macOS 候选支持 Apple Silicon 和 macOS 15 及以上版本；未完成 Apple 公证。

## 登录协议升级

新版企业模型使用 oidc-llm Token 授权，需要匹配的服务端发现配置。旧 Key Binding 配置不能直接复用；维护者先在测试环境验证并更新签名学校配置，再开放新版下载。升级后需要重新登录，个人 API Key 和会话不受影响。

## 账户、配额和注销

点击左下角头像打开账户菜单，查看已登录姓名、使用情况、重置时间和资源池。可展开明细、刷新配额或退出登录。具体数值与可用资源以服务端返回为准；个人模型服务的额度不在这里展示。

配额扩展只查询配置的 ECNU 账户档案，保留配额窗口和资源池信息。公版 OIDC 只负责身份、Key 和模型；配额是本发行的学校扩展。

## 学校配置与个人设置

学校统一维护企业登录、模型目录与能力、上下文和输出上限、媒体服务、品牌、服务开关及更新源。默认学校配置可独立更新，用户也可编辑生效文件；无需为了模型能力变化重新登录。设置中仍可添加个人模型，并保留已保存的个人偏好。

当前发行配置将 `ecnu-max` 设为文本模型，上下文为 512K（524,288 tokens），最大输出为 384K（393,216 tokens）。默认开启图片辅助：`ecnu-plus` 先观察图片，`ecnu-max` 根据文字证据回答，原始附件保留在会话中。直接选择原生图片模型时，图片仍交给所选模型。标准模式由 DSH 在上下文压力达到阈值时自动压缩。

所有版本统一读取 `config/eduwork.jsonc`，可从设置打开。修改后退出并重启；远程更新保留手工修改。自动改写前只保留一份 `data/configuration/eduwork.previous.jsonc`，用于失败回退。会话、工作区、记忆、个人 Provider 和 Key、默认模型选择及已保存的用户偏好不会被学校配置替换。

仓库和 CI 仅提供模板。实际 Client ID 等部署参数通过签名学校配置在首次启动时下载，详见[配置示例](../edition/desktop-examples/README.md)。这些参数及账号令牌不提交公开仓库。

## 学校能力与公共能力

- 校内搜索由学校插件提供。通用网页和文献搜索、技能中心、Studio、文件预览、记忆、邮件、本机语音来自公版。
- 学校图像与语音服务由公版的 OpenAI 兼容适配器按配置和账号权限启用，不再包含学校媒体插件。企业示例含 `media` 段；`media.providers: []` 可显式关闭云端媒体，旧配置迁移时会把学校默认媒体服务写入统一配置文件。缺少远程语音服务时，可使用已就绪的本机 TTS/ASR。
- 学校发行已通过配置启用活跃心跳：登录学校账号后，首次进入前台、恢复前台或登录完成时上报，前台默认每 10 分钟一次；转入后台尽力上报一次后暂停。未登录学校账号时不发送，使用其他模型不会让其他机构自动接收心跳。上报字段和鉴权方式见[活跃心跳插件](../edition/plugins/chatecnu-active-heartbeat/README.md)。
- 对话与 Studio 共用生成、预览和下载。Studio 默认折叠，主动打开或关闭后会记住偏好。

## 常见问题

**没有显示学校入口**：确认使用学校提供的已配置 ECNU 发行包；若仍缺失入口，请导出诊断并联系维护者，无需自行修改配置。

**浏览器已登录，客户端仍未连接模型**：检查引导是否还有模型凭据授权待确认，并在学校/企业服务页面查看实际连接状态。保留错误信息反馈维护者，不要复制或公开账号令牌。

**学校服务暂不可用**：可配置自己的模型继续一般工作。校内搜索、学校配额和远程媒体需要各自的学校服务支持，不能用个人模型连接状态判断它们已就绪。

**程序移动后找不到工作区文件**：移动整个绿色目录前应完全退出。外部工作区文件仍留在原位置，不会随程序目录一起移动。用户会话与配置不能作为缓存清理。

公共使用方式见 [EduWork 使用指南](https://github.com/ecnu/EduWork/blob/main/docs/USER_GUIDE.md)，学校发行的源码装配见[构建与协作](BUILD.md)。
