# 试听与分享用的小体积副本

默认交付 MP3，保留服务下载的 FLAC/WAV 作为制作源；不需要把无损源再复制到每个 HTML 分享目录。用户明确要求无损或指定格式时遵从。转码是本地派生副本，不重新提交音乐任务，也不改变服务端下载接口。源文件已是 MP3 时直接复用，不反复有损编码。

## 音频和作品页

使用技能随附脚本，输入和输出均为当前工作区真实路径，输出目录须已存在，使用新的文件名：

```text
node <技能目录>/scripts/prepare-media.mjs audio <下载的audio.flac> <作品名.mp3>
```

脚本复用已安装媒体运行时中的 FFmpeg/FFprobe，不下载组件；未自动找到时，可指定 `--ffmpeg <实际绝对路径>`，FFprobe 默认位于相邻目录，也可用 `--ffprobe` 指定。不要猜路径、改扩展名冒充 MP3 或因转码失败重新生成歌曲。缺少编码器时保留原件，说明尚未生成轻量副本。

默认 MP3 192 kbps，保留单声道/双声道，采样率 44.1 或 48 kHz；约每分钟 1.44 MB（十进制）。完整曲长，不裁剪、不变速、不降音量。已有 MP3 则复制音频流，不再次压缩。它是有损分享版，无损源仍供后续制作、转谱或用户索取。

成功后使用回执的 MP3 路径作为 `ecnu_music_export_song.audio_path`，独立音频附件也交付此 MP3。导出工具本身原样复制输入，不会隐式转码。HTML 与后续校时从同一 MP3 开始，避免先绑定 FLAC 时间轴再偷偷换音频。已有时间轴绑定其他音频哈希时，默认保留旧版；转码后需核对编解码延迟及首、中、尾同步，经过确认再导入字幕并重新导出，不能仅修改哈希绕过校验。

## 歌曲视频

默认手机分享：竖屏 720×1280 / 横屏 1280×720、30 fps；背景加可读歌词，不添加逐帧噪声、细密闪动纹理等难压缩效果。新项目在目标尺寸排版，沿用高分辨率布局时统一缩放并检查文字，不能只改组合宽高导致裁切。用户指定更高画质时使用其要求。

优先用无损源作为视频的唯一主音轨，避免 MP3→AAC 再次编码。现有视频工具未暴露编码质量参数时，先正常渲染，再运行：

```text
node <技能目录>/scripts/prepare-media.mjs video <渲染的原片.mp4> <作品名-mobile.mp4>
```

预设为 H.264、CRF 24、medium、最高 720p（不放大小视频）、yuv420p、AAC 160 kbps、faststart。画面码率峰值约束 1.8 Mbps；保留 30 fps 以下的原帧率，更高则降到 30 fps。已有 AAC 且不超过 192 kbps 时复制音轨，不重复有损编码。不改变完整时长，不加 `-shortest`、循环、裁剪或加速；有旋转元数据/非方形像素时先明确规范化处理，脚本不会猜方向。

默认只交付合适的分享版，保留源工程与原片，不反复压缩已压缩版本。最终大小取决于画面，不能承诺固定 MB；用户有大小上限时先根据完整曲长算预算，音频亦计入总量。若新文件反而更大，优先保留兼容的原片并检查原因。

## 执行与核对

脚本拒绝覆盖已有输出，写入临时文件后核对格式与时长（容许编码封装差异不超过 0.25 秒），再发布正式文件和 `<输出>.media.json` 回执，记录实际大小、时长、源文件、预设和节省比例。进度输出到 stdout，诊断到 stderr；较长任务按 Host 的后台执行机制保留 PID、开始时间和两份日志，不设置外层硬超时。只有退出成功且回执/文件实际存在才算完成。

交付前检查音频能解码/拖动，视频首、中、尾文字清晰、没有裁切、音轨完整。时长与编码校验不等于主观音质或所有设备播放验收。使用 Host 的 `present` 入口登记真实 MP3/MP4 和作品页；无需把技术回执展示成用户附件。
