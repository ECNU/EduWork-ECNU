# EduWork@ECNU 0.4.14-dev.20261116.2

## 更新内容

- 日历默认按月打开，考试和假期直接标出起止日期。点选日期可以查看或新建日程，切换月历和周历会保留选中的日期。学年总览可跳到关心的月份。[日历改版](https://github.com/ECNU/EduWork/pull/326)
- 新增首次使用引导。可从「应用 → 使用教程」打开学校在线教程，离线时也能阅读随包的快速入门。[公版教程](https://github.com/ECNU/EduWork/pull/252) · [学校教程](https://github.com/ECNU/EduWork-ECNU/pull/95)
- 应用在后台收到待处理通知时，Windows 任务栏和 macOS Dock 会显示数量；Windows 任务栏图标也会闪烁提醒。[桌面通知](https://github.com/ECNU/EduWork/pull/327)
- Windows 无法解密本地凭据时，会保留原凭据文件并继续启动，可重新登录恢复使用。[启动恢复](https://github.com/ECNU/EduWork/pull/109)

## What's new

- The calendar opens in month view and shows exam and vacation dates directly. Select a day to see or add events. Switching between month and week keeps your place. The academic-year overview links to individual months.
- A first-run tour introduces the workspace. Open the school’s online guide from the application menu, or read the bundled quick start offline.
- Pending notifications now have a count on the Windows taskbar and macOS Dock when the app is in the background. The Windows taskbar icon can also flash.
- If Windows cannot decrypt stored credentials, EduWork preserves the original file and continues starting so you can sign in again.
