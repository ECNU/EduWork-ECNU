# ECNU 校历

**简体中文** | [English](README_EN.md)

提供学校签名配置中的各学年校历，首次离线可使用内置的 2026–2027 学年数据，包含秋季、春季和暑期短学期、教学与考试阶段、寒暑假，以及注册、报到、运动会等具体事项。周次与阶段由公共教育校历插件计算和展示，具体事项转换为普通全天日程；不根据法定调休推断课程变化。

在 DSH 或 EduWork 中先启用 `@eduwork/dsh-calendar`、`@eduwork/dsh-academic-calendar`，再启用本包。日历面板选择“华东师范大学 2026-2027 学年校历”，周标题显示学年、学期、周次与单双周，月视图提供周次列及阶段背景。考试周包含周末，寒暑假不显示教学周；暑期短学期独立编号为第 1–4 周。切换校历同时切换其背景与具体事项。

学校发行版从锁定的公版继承通用日历、订阅和教学日历。学校通过[发行配置](../../distribution.json)注册校历数据，并为日历管理技能附加校历使用说明。

学校公布新学年或调整假期后，在配置发行计划的 `configuration.academicCalendars` 中列出要保留的学年 JSON。修订同一学年时提高数据内的 `revision`，保持已有事项的 `uid`，同时提高配置和发行修订号。客户端下次启动时应用下载的配置，面板与问答共用同一份数据。见[配置发布说明](../../../docs/BUILD.md)。

内置数据的来源与官方日期见 `data/2026-2027.json`。官方考试日期保留原件范围，按周展示时秋季考试阶段覆盖到 2027-01-17，春季覆盖到 2027-06-27。短学期至 2027-07-23，暑假为校历网格给出的 07-26 至 09-05；未标明的日期不推断。

`ctx.ecnuCalendar.describeDate(date)` 可查询本数据集。AI 校历问答使用公共 `academic_calendar_query`；`ready` 和 `integration` 分别表示数据加载和公开接口登记，接入错误保留在 `integrationError`。没有教育校历服务时仍可直接查询数据，不读取学校账号或发起网络请求。个人课表通过公共教育插件的结构化导入接口接入，详见该包示例；真实个人文件不随本包发布。
