# ChatECNU 云端

[English](README_EN.md)

侧栏优先保留 EduWork 本地工作区与会话，关联云端项目后仍使用原生工作区入口。ChatECNU 位于工作区下方，默认收起；展开后可浏览最近会话和项目，两个分组均可折叠，并记住整个区域的展开状态。关联和来源使用图标及悬浮／键盘提示。会话按时间分组，可筛选标题并继续加载更早记录；点击后在完整页面阅读历史。复用学校账户只读服务的固定查询，登录和服务配置由发行方提供。普通会话可接续；项目以本地工作区和云端知识库的关联为入口。

预览仅展示用户和助手的可见文本，不渲染云端 HTML、不加载外部图片、不执行工具。遇到尚不支持的消息会明确提示；首期单次预览最多 1,000 条消息、1 MB 文本。

本地工作区与 ChatECNU 分组共用侧栏滚动，分组内部不限高、不单独滚动；通过折叠、最近三条及「查看全部」入口控制长度。头像区域固定，右侧内容页独立滚动。项目在侧栏、列表和详情页使用一致状态图标：地球表示云端项目，链条表示已关联工作区；悬浮或键盘聚焦可查看工作区名称和资料按需读取的说明。关联不表示资料已下载或同步。

侧栏分组明确标注「最近 3 条」「预览 3 项」，不足三条时显示实际数量；「查看全部会话」「查看全部项目」始终使用可见文字，折叠分组后仍可打开完整列表。展开项目后也标明会话预览数量，并提供「查看全部会话与资料」入口，避免将侧栏预览误认为全部内容。

侧栏与完整会话列表共用状态图标：地球表示云端预览，文件夹表示本地会话；已接续条目直接打开本地会话，旁边的地球按钮可查看云端原记录。悬浮或键盘聚焦可查看解释。普通列表合并默认工作区会话及普通云端会话的本地接续；项目列表只合并该项目及其关联工作区的会话，按最近活动排序并去重。两个分组标题旁分别提供「查看全部会话」「查看全部项目」，打开各自的独立页面。

打开云端会话只预览历史。首次在阅读页底部发送时才带入历史并创建本地接续，发送前明确提示后续消息保存在本地、不回写云端。普通会话默认使用本地默认工作区，可通过现有选择器更换。已接续的侧栏条目直接打开同一个本地会话，也可另行查看云端原记录。

项目可展开查看会话，也可打开项目页查看会话与云端资料。第一次发送新问题或接续项目会话时，用户确认该项目唯一的本地工作区；随后项目中的会话固定在这个工作区继续，不能改选其他工作区。本地工作区标题旁的关联图标和会话页项目标记可打开云端项目；本地接续会话保留在所属工作区，来源图标可查看云端原记录。取消首次设置保留草稿，不建立关联。只有服务端明确提供项目与 Notebook 的对应关系时才关联会话，其余资料库单独列出。资料正文按需只读预览，每次访问重新校验云端权限；空正文和读取失败分别提示，超长正文最多展示 200,000 字符。浏览本身不建立工作区授权，也不持久化浏览内容。

使用 DSH 的 storageDomain 与 workspaceRegistry。工作区引用稳定 ID，显示名变化不改变绑定；目录缺失或会话已经移走时返回明确状态，不创建目录、不移动会话、不自动清空历史绑定。

项目与工作区建立明确的一对一关联后，该工作区内的会话自动获得三个只读工具：`ecnu_project_search` 检索资料、`ecnu_project_sources` 列出来源、`ecnu_project_read_source` 分段读取解析正文。Host 根据会话实际工作目录决定项目范围，Agent 不能指定其他项目或工作区。知识授权按账号、学校 Profile、模型基址和 Notebook 服务基址隔离；不会继承旧的续聊默认目录。每次工具执行重新确认绑定、来源范围与云端权限。

项目列表中的「已关联工作区」可解除关联；即使云端项目已删除或共享权限已撤销，本地关联仍可移除。解除关联停止该工作区的项目工具，保留任务和文件。资料按需读取，不下载原文件、不自动同步，不增加 OAuth 授权流程。

## 接入

侧栏合并原型还需要 UI Workspace 提供通用 `sidebar.workspaces.content` 和 `sidebar.workspaces.group.actions` 扩展点，以及通过 `data-sidebar-workspace-flow="outer"` 选择共用外层滚动。这些不是 DSH 0.2.2-rc.3 已发布的接口，当前仅在隔离本地预览中验证；尚不能直接装入未提供扩展点的正式桌面。

发行方显式装载服务，配置已存在的学校 profile 和模型 API 基址：

```json
{
  "profileID": "school",
  "modelBaseURL": "https://example.org/open/api/v1"
}
```

Host 必须提供既有 OIDC 的 modelAuthorization 与 accountIdentity。后者必须返回经验证的稳定账号标识；缺少该方法时返回 identity_unavailable，不用用户名或临时 ID 猜测身份。这是已有 Host 身份接口的组件依赖，不新增 OAuth scope 或补授权流程。当前源码不修改默认装配、发行锁或用户配置；应在对应公共包正式可用后集成。

账号标识、学校 profile 和环境基址共同形成存储分区，不持久化令牌。正常令牌续期保留绑定；重新登录、换号与退出使旧页面的选择凭据失效。新账号不能读取旧账号映射，重启保留已提交的绑定。浏览 RPC 只供本机所有者使用。

会话浏览能力同时需要同一学校 profile 的 `ecnuAiconsole` 只读服务；它与 Agent 查询共用 reader，不另建鉴权或 HTTP 客户端。缺少服务或读取权限时显示明确状态。使用 DSH 0.2.2-rc.3 的侧栏、主面板、按钮与图标组件。

项目适配器通过同一 OIDC 服务访问固定 Notebook MCP 端点，仅开放列举资料库、详情、来源列表、知识检索与来源正文五种读取。`workerBaseURL` 默认由模型服务的同一来源派生为 `/api/worker/v1`，可由可信发行配置显式指定；不得跨来源。界面不能提供 URL 或任意工具名称。MCP 的 POST 使用现有 Host 服务鉴权，重试只限可重放的只读请求。项目读取支持取消并设有总超时。

模型基址默认要求 HTTPS。隔离的 HTTP 联调须在本插件与学校登录 Profile 中显式设置 `allowInsecureDevelopment: true`；服务地址仍须通过 OIDC Host 校验。HTTP 与 HTTPS 基址形成不同存储分区，不能借此访问另一环境的绑定。

## Host 方法

| 方法 | 用途 |
| --- | --- |
| projectWorkspace(projectID) | 获取项目的默认工作区及目录有效状态 |
| bindProject(projectID, workspaceID) | 设置以后接续时的默认选择，不迁移既有会话 |
| unbindProject(projectID) | 仅移除默认选择 |
| conversation(conversationID) | 查询已登记的本地会话，供接续前查重 |
| rememberConversation(conversationID, sessionID, workspaceID, projectID?) | 登记已创建且属于工作区的本地会话；重复登记幂等，冲突拒绝覆盖 |
| forgetConversation(conversationID) | 用户明确修复时解除登记，不删除本地会话 |
| projectForSession(sessionID) | 仅返回当前账号、环境和当前会话绑定的项目；不继承同目录其他会话的项目 |

这些兼容方法只能由可信 Host 适配器调用，与独立的工作区知识授权分开保存。UI 或 Agent 不能直接提供账号、环境或任意本地存储键。项目 ID 必须来自后续服务端适配器确认的字段，不将云 workspaceId 推断成 Notebook ID。

## 边界与验证

导入复用官方 Session 校验、sessionPersistence 持久化和 workspaceRegistry 登记，不启动模型。用户确认后保存本地恢复记录；中断重试复用同一个会话 ID，校验已写入前缀并补齐，禁止覆盖不同历史。离开页面会请求取消，已写入的数据保留供下次恢复。原目录失效或会话被移动时提示修复，不生成重复会话。

导入前重新读取会话摘要与消息，核对预览快照；来源的项目字段只能作为本次会话的显式绑定，不推断 Notebook ID。导入历史不会包含云端 system、工具执行、思考过程或计费记录，使用独立来源标记。旧会话绑定不授予工作区资料访问权；新的知识关联必须由用户在项目页明确建立，资料读取仍须由平台鉴权。没有下载、双向同步或云端写操作。

使用锁定的 DSH Runtime 设置 EDUWORK_TEST_RUNTIME，在学校仓根运行：

```powershell
node --import ./edition/test/runtime-resolver.mjs --test edition/plugins/ecnu-cloud/test/*.test.mjs
```

测试使用真实 DSH JSON 存储和工作区注册表、合成账号，覆盖重启、账号和环境隔离、换绑、重复／冲突、目录失效、并发账号切换及存储失败。工作区知识测试还使用真实 RC3 工具注册与 MCP 传输，覆盖工具按工作区激活、来源边界、解绑撤权和服务地址隔离。不代表云端服务或正式桌面已经完成联调。
